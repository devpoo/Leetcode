## Approach

Brute force would be to find the diff between all the sub arrays you can create.

Two pointer method, left will point at the lowest so far. if `prices[l] < prices[r] `
compute the profit and maxProfit. Otherwise move left to right and keep moving forward.

## Complexity
| Type  | Complexity | Why                         |
| ----- | ---------- | --------------------------- |
| Time  | `O(n)`     | Iterates the array once     |
| Space | `O(1)`     | just the local storage vars |

## Code
``` java
class Solution {
    public int maxProfit(int[] prices) {
        int l = 0;
        int r = 1;
        int n = prices.length;
        int maxP = 0;
        while (r < n) {
            if (prices[l] < prices[r]) {
                int profit = prices[r] - prices[l];
                maxP = Math.max(profit, maxP);
            } else {
                l = r;
            }
            r++;
        }
        return maxP;
    }
}
```
