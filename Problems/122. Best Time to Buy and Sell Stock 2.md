## Approach

Each time there is a diff in prices add to the profit.

## Complexity
| Type  | Complexity | Why                         |
| ----- | ---------- | --------------------------- |
| Time  | `O(n)`     | Iterates the array once     |
| Space | `O(1)`     | just the local storage vars |

## Code
```java
class Solution {
    public int maxProfit(int[] prices) {

        int profit = 0;
        int n = prices.length;

        for (int i = 1; i < n; i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}
```
