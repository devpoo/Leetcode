
### Solution:
Keep a var maxLength that will be incremented when all strings have that character.

get the first character and if the maxLength == stringLength -> return the str

else, 

iterate over the next strings 
	if string length reached return the str.
	 else get the next char and compare with the curr char. if unequal return the string from 0 to maxLength


``` java
class Solution {
    public String longestCommonPrefix(String[] strs) {

        int maxLength = 0;

        while (true) {
            String firstStr = strs[0];
            if (firstStr.length() == length)
                return firstStr;
            char curr = firstStr.charAt(maxLength);

            for (int i = 1; i < strs.length; i++) {

                if (strs[i].length() == maxLength)
                    return strs[i];
                char c = strs[i].charAt(maxLength);

                if (c != curr)
                    return strs[i].substring(0, maxLength);
            }
            maxLength++;
        }
    }
}
```
