## Problem

Given a `9 x 9` board, check whether the filled cells are valid. Each row, each column and each `3 x 3` box must contain the digits `1-9` with no repeats. Empty cells are `'.'`. The board does not need to be solvable.

## Approach

Keep one `HashSet` for every row, every column and every `3 x 3` box. Walk the board once. For each filled cell, if the digit is already in its row, column or box set, return `false`. Otherwise add it to all three sets.

## Points to Remember

**1. Box index formula**

```java
int k = (i/3)*3 + j/3;
```


**2. Initialization of the HashSet arrays**

```java
HashSet<Character>[] rows = new HashSet[9]
```

## Complexity

|Type|Complexity|Why|
|---|---|---|
|Time|O(1)|Fixed `9 x 9` board, 81 cells with O(1) HashSet operations (O(n²) for an `n x n` board)|
|Space|O(1)|At most 81 digits in each of the three set groups (O(n²) for an `n x n` board)|
## Code

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        HashSet<Character>[] rows = new HashSet[9];
        HashSet<Character>[] cols = new HashSet[9];
        HashSet<Character>[] sub = new HashSet[9];

        for (int i = 0; i < 9; i++) {
            rows[i] = new HashSet<Character>();
            cols[i] = new HashSet<Character>();
            sub[i] = new HashSet<Character>();
        }

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {

                char c = board[i][j];
                if (c == '.')
                    continue;
                if (rows[i].contains(c))
                    return false;
                rows[i].add(c);

                if (cols[j].contains(c))
                    return false;
                cols[j].add(c);

                int k = i / 3 * 3 + j / 3;
                if (sub[k].contains(c))
                    return false;
                sub[k].add(c);

            }
        }
        return true;
    }
}
```
