## Solution
`left[0] = 1`
`right[n-1] = 1`
create leftProduct which is `left[i] = left[i-1]*nums[i-1]`
create rightProduct which is `right[i] = right[i+1]*nums[i+1]`

## Complexity
| Type  | Complexity | Why                        |
| ----- | ---------- | -------------------------- |
| Time  | O(n)       | Single pass over the array |
| Space | O(n)       | left and right             |
## Code
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] left = new int[n];
        int[] right = new int[n];
        int[] result = new int[n];

        //create left sum by multiplying the array till 
        left[0] = 1;
        for (int i = 1; i < nums.length; i++) {
            left[i] = left[i - 1] * nums[i - 1];
        }

        right[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1] * nums[i + 1];
        }

        for (int i = 0; i < n; i++) {
            result[i] = right[i] * left[i];
        }

        return result;
    }
}
```
