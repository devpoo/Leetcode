## Approach

Initialize `P0 as pointer to zeros P2 as 2 collector`
until `curr <= P2` check 
	`if curr==2`  swap it all the way to P2 element and decrement p2. Don't increment curr as it can have another 2 or 0.
	`else if curr == 0` swap the curr to P0. Increment P0 and curr
	otherwise it has 1 and increment curr;
	

## Complexity

| Type  | Complexity | Why |
| ----- | ---------- | --- |
| Time  | `O(n)`     |     |
| Space | `O(1)`     |     |

## Code
```java
class Solution {
    public void sortColors(int[] nums) {

        int p0 = 0;
        int curr = 0;
        int p2 = nums.length-1;

        while(curr <= p2) {
            if(nums[curr] == 2){
                int tmp = nums[curr];
                nums[curr]=nums[p2];
                nums[p2] = tmp;
                p2--;
            } else if(nums[curr]==0) {
                nums[curr] = nums[p0];
                nums[p0] = 0;
                p0++;
                curr++;
            } else {
                curr++;
            }
        }
    }
}
```
