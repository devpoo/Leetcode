### Problem

Given an integer `numRows`, return the first numRows of **Pascal's triangle**.
In **Pascal's triangle**, each number is the sum of the two numbers directly above it as shown:

### Approach

Initialize the result list with the first row as `[1]`. 
For rest of rows - 
Create a temp list with adding zero to the beginning and end of the prev row. 
Then iterate till `prev.size() + 1` and add `temp[j] + temp[j+1]`

## Complexity
| Type  | Complexity | Why                                                              |
| ----- | ---------- | ---------------------------------------------------------------- |
| Time  | `O(n²)`    | Row `i` has `i + 1` cells, so the total work is 1 + 2 + ... + n. |
| Space | `O(n²)`    | `result` stores every row. The `temp` list is only `O(n)` extra. |
## Code

```java
class Solution {

    public List<List<Integer>> generate(int numRows) {

        List<List<Integer>> result = new ArrayList<>();
        result.add(new ArrayList<>(List.of(1)));

        for (int i = 0; i < numRows - 1; i++) {
            List<Integer> res = new ArrayList<>();
            List<Integer> prev = result.get(result.size() - 1);

            // pad the prev row with zero
            List<Integer> temp = new ArrayList<>();
            temp.add(0);
            temp.addAll(prev);
            temp.add(0);

            for (int j = 0; j < prev.size() + 1; j++) {
                res.add(temp.get(j) + temp.get(j + 1));
            }
            result.add(res);
        }
        return result;
    }
}
```



## Points to Remember
- The padded zeros handle the edges, so the first and last cells of every row are always 1 with no special case.
- The outer loop runs `numRows - 1` times because row 1 is already added.
