
## Solution
1. Brute force method is to use a set to store the rows and cols that contain zero. That entails extra space
2. Space efficient solution:
	1. Use the 1st row and 1st col as the set. If the i, j has a zero then mark `m[i][0] and m[0][j] ` as zero.
	2. !!! IMP - One edge case is when the  first col has zeros and first row does not. If we update the the `m[0][0]` to save row and col , it will cause issues. So we use it for only for row. For col we use another boolean var isCol.
	3. Then we separately mark the matrix, first row and first col with zeros


## Complexity

| Type  | Complexity   | Why              |
| ----- | ------------ | ---------------- |
| Time  | 2 * `O(m*n)` | Traverse 2 times |
| Space | `O(1)`       |                  |

## Code
```java
class Solution {
    public void setZeroes(int[][] matrix) {

        boolean isCol = false;

        int r = matrix.length;
        int c = matrix[0].length;

        for (int i = 0; i < r; i++) {

            if (matrix[i][0] == 0)
                isCol = true;

            for (int j = 1; j < c; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        for (int i = 1; i < r; i++) {
            for (int j = 1; j < c; j++) {
                if (matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
                if (matrix[i][0] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        if (matrix[0][0] == 0) {
            for (int j = 1; j < c; j++) {
                matrix[0][j] = 0;
            }
        }

        if (isCol) {
            for (int i = 0; i < r; i++) {
                matrix[i][0] = 0;
            }
        }
    }
}
```
