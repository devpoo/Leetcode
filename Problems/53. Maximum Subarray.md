## Solution
keep track of maxLocal(currSum) and maxGlobal(maxSum)
Sample Examples: 
```
5 5 -30 40

30 30 -10 100
```

## Complexity

| Type  | Complexity | Why                  |
| ----- | ---------- | -------------------- |
| Time  | `O(n)`     | Traveses all numbers |
| Space | `O(1)`     | Saves only 2 vars    |

## Code
``` java
class Solution {
    public int maxSubArray(int[] nums) {
        int maxSum = nums[0];
        int currSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            currSum = Math.max(nums[i], currSum + nums[i]);
            maxSum = Math.max(maxSum, currSum);
        }
        return maxSum;
        // 5 5 -30 40
    }
}
```
